# Учебный Telegram-бот: запуск на Windows

Эта версия использует 8 учебных слов. Сайт, база данных и языковая модель не подключаются.
Платные сервисы и Docker не нужны. Для Telegram и установки библиотек требуется интернет.

## Что можно проверить

- «📚 Карточки слов»: слово → показать перевод → оценить, насколько легко вспомнилось.
- Мини-тест: 5 вопросов с 4 вариантами перевода, результат после каждого ответа и в конце.
- Сложные слова: появляются после неправильных ответов и оценки «Не помню».
- «☀️ Практика дня»: 3 карточки для самостоятельного вспоминания, затем 2 предложения
  с пропуском. Пропущенное английское слово нужно отправить обычным сообщением,
  вариантов ответа нет. Приоритет сохраняется за сложными словами и словами к повторению.
- Главное меню, помощь, выбор уровня, остановка занятия и просмотр прогресса.
- «💬 Разговор на английском» сообщает, что LLM пока не подключена.

Оценка «Не помню» назначает повторение через 10 минут, «С трудом» — через день,
«Помню» — через 3 дня, «Легко» — через 7 дней. Это демонстрационные интервалы,
а не настоящий SM-2 проекта. После интеграции даты будет определять общий сервер.
Сложные слова можно повторять внепланово. Они упорядочены по накопленным ошибкам;
правильный ответ не стирает прошлые ошибки. Мини-тест проверяет выбор перевода.
Практика дня отдельно проверяет вставку английского слова в предложение: для каждого
из 8 слов заготовлены предложение, русская подсказка, допустимый ответ и объяснение ошибки.
Регистр, пробелы по краям и точка в конце ответа не влияют на проверку.
Верный ответ назначает повторение через 3 дня, неверный — через 10 минут.
Это проверка по заранее заданным ответам без LLM; свободной беседы пока нет.

Итоги практики дня показывают отдельно 3 пройденные карточки и правильные ответы
в 2 заданиях с пропуском. Самооценки карточек не включаются в число правильных ответов.
В «Моём прогрессе» правильные ответы относятся только к мини-тестам и пропускам.

Данные каждого пользователя разделены и хранятся **в оперативной памяти**.
После остановки или перезапуска программы прогресс исчезнет. Это не личный словарь с сайта.
Выбор уровня сохраняется на время запуска, но пока не изменяет учебные задания.
Практика дня считается завершённой только после всех 5 шагов (3 оценки и 2 ответа)
и доступна раз в день по UTC: новый день начинается в 03:00 по Москве.
Прерванную практику можно начать заново; уже записанные оценки и ответы остаются.
После завершения можно продолжать заниматься в мини-тесте. Автоматических напоминаний нет.

## 1. Создай своего бота

В Telegram открой официальный [BotFather](https://t.me/BotFather).
Нажми «Запустить», отправь `/newbot`, выбери название и уникальное имя на `bot`.
Сохрани секретный токен. Не отправляй его помощнику и не публикуй на GitHub.

## 2. Установи Python 3.12

Скачай Python 3.12 с [официального сайта](https://www.python.org/downloads/windows/).
При установке оставь Python Launcher включённым. Он нужен команде `py -3.12`.
Ollama и модель на этом этапе устанавливать не требуется.

## 3. Распакуй папку бота

Если получила ZIP-архив, сначала нажми по нему правой кнопкой мыши → «Извлечь всё».
Не запускай файлы прямо из архива. В полученной папке найди `install-demo.cmd`.
В полном проекте `coursework-tp-2026` открой папку `bot`: файлы запуска находятся
в ней, рядом с этой инструкцией (`F:\coursework-tp-2026\bot` при текущем расположении проекта).

Дважды нажми `install-demo.cmd`. Появится окно установки библиотек.
Дождись сообщения `Ready`. Если появилась ошибка, не продолжай вслепую:
сохрани её текст и попроси помочь. Установка не изменяет секретный файл, если он уже существует.

## 4. Сохрани токен на своём компьютере

В папке бота после установки появится файл `.env`. Открой его через Блокнот:
правая кнопка → «Открыть с помощью» → «Блокнот».
Вставь токен сразу после `BOT_TOKEN=`, без пробелов и кавычек, и сохрани файл.

Не сохраняй его под именем `.env.txt`. В Проводнике включи отображение расширений файлов,
если не уверена. `.env.example` — образец; настоящий токен должен быть именно в `.env`.
Настоящий `.env` исключён из Git. В скачиваемый архив он не включается.

## 5. Запусти и проверь

Если бот уже запущен, сначала отдельно согласуй его остановку и перезапуск:
временный прогресс при этом исчезнет. Не запускай вторую копию с тем же токеном.
Если бот не запущен, дважды нажми `start-demo.cmd`. Оставь окно открытым.
Открой своего бота в Telegram, нажми «Запустить» или отправь `/start`.

Попробуй:

1. «📚 Карточки слов» → «Показать перевод» → «Не помню».
2. «🔁 Сложные слова» — там появится забытое слово.
3. «📝 Мини-тест» — ответь на 5 вопросов с 4 вариантами перевода и посмотри итог.
4. «☀️ Практика дня» — оцени 3 карточки, затем отправь текстовые ответы на 2 пропуска.
   Один ответ можно написать с большой буквы, с пробелами и точкой в конце.
   После каждого ответа проверь правильное слово и заполненное предложение.
   При ошибке появляется короткое объяснение. В итогах карточки и ответы указаны отдельно.
5. «📊 Мой прогресс», «🎚 Уровень» и «💬 Разговор на английском».
6. Во время задания открой «❓ Помощь» или `/progress`, затем продолжи тот же шаг.
   Они не прерывают занятие. Выбор другого режима и `/start` начинают новый сценарий.
7. В незавершённой практике отправь `/stop`. Затем открой её снова: она должна начаться
   с первого шага и не считаться выполненной за день. Уже данные ответы остаются в прогрессе.

Команда `/stop` прекращает текущее занятие, но не выключает программу. Уже записанные
результаты остаются до перезапуска. `/start` открывает главное меню без очистки результатов.
Кнопки от старых заданий не должны засчитывать ответы повторно. При смене режима
текущее незавершённое занятие заменяется новым; уже данные ответы сохраняются.
Команды и кнопки меню не засчитываются как ответы на пропуски. Нераспознанные команды,
пустые сообщения и сообщения без текста тоже не засчитываются.
Кнопки прежнего меню без эмодзи продолжают работать, а `/start` показывает новое меню.

Для выключения нажми `Ctrl+C` в окне программы. При выключенном или спящем компьютере
бот не отвечает. Не запускай две копии программы с одним токеном.
При первом использовании нужен новый бот без ранее настроенного webhook.
Настройки webhook программа автоматически не удаляет.

## Проверки для разработки

Из папки `bot` полного проекта можно выполнить тесты без установки дополнительных инструментов:

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

Тесты используют имитацию Telegram без сети и без чтения `.env`. Проверяются новое меню,
мини-тест из 5 вопросов, практика из 3 карточек и 2 пропусков, правильные и неправильные
ответы, нормализация ввода, интервалы, переходы между режимами, прерывание практики,
повторные нажатия старых кнопок и разделение пользователей.

Если dev-зависимости уже установлены, дополнительно доступны:

```powershell
python -m pytest tests -q
python -m ruff check bot tests
```

Демонстрационный адаптер `bot/demo.py` не обращается к базе данных. Рабочий бот после
интеграции должен пользоваться общим backend API через `bot/api_client.py`.
Обычный запуск `python -m bot.main` сохраняет прежнее приветствие проекта;
учебные режимы включаются явно: `python -m bot.main --demo`.

Проверки с подставными ответами Telegram не заменяют разговор с настоящим ботом.
Для ручной проверки используй своего бота и локальный токен.
