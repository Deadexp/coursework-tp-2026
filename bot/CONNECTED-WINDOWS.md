# Общий личный словарь: сайт и Telegram на Windows

Подключённый режим работает через backend и PostgreSQL. Личный словарь и история
повторений общие для сайта и бота. Постоянной копии словаря в боте нет.
Деморежим запускается отдельно: 8 учебных слов, временные результаты в памяти.

## Перед запуском

Нужны уже установленные Docker Desktop и Python 3.12 с Python Launcher.
Если программы отсутствуют, согласуйте их установку отдельно.
Если бот уже работает, сначала согласуйте его остановку и переключение режима:
не запускайте второй процесс с тем же токеном. Перезапуск демо теряет его прогресс.
Эти инструкции не сбрасывают базу и не удаляют Docker-тома.

## 1. Настройки сервера

В корне проекта используется секретный `.env`. Если он существует, сохраняйте
текущие настройки БД и LLM. Образец переменных — корневой `.env.example`.
Настоящие ключи не публикуйте и не отправляйте в чат.

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен вашего Telegram-бота из BotFather |
| `BOT_USERNAME` | Публичное имя этого же бота без @ |
| `BOT_SERVICE_TOKEN` | Случайный секрет не короче 32 символов, одинаковый у API и бота |
| `WEBSITE_URL` | Адрес сайта в инструкции подключения, локально `http://localhost:5173` |
| `DATABASE_URL`, `POSTGRES_*` | Существующие настройки PostgreSQL проекта |

Сгенерируйте служебный секрет локально в менеджере паролей и вставьте в настройки.
Пустое значение и `change-me` не дают доступ к API. Это другой ключ, не токен BotFather.

## 2. Сервер, база и сайт

Из корня проекта после запуска Docker Desktop:

```powershell
docker compose up -d --build db api web
```

Сервер: http://localhost:8000/docs, сайт: http://localhost:5173.
API применяет существующие миграции автоматически. Не выполняйте сброс БД и удаление томов.
Загружать учебный контент для добавления собственных слов не требуется.

## 3. Подключённый бот: выберите один способ

**Windows без контейнера бота.** В папке `bot` запустите `install-demo.cmd`.
Несмотря на прежнее имя, установщик загружает библиотеки для обоих режимов.
Он создаёт `bot/.env` из образца только при отсутствии файла.

В `bot/.env` задайте токен BotFather, тот же `BOT_SERVICE_TOKEN`, что у API,
`API_BASE_URL=http://localhost:8000`, `WEBSITE_URL=http://localhost:5173`.
Запустите `start-connected.cmd`. Равнозначная команда из папки `bot`:

```powershell
.\.venv\Scripts\python.exe -m bot.main --connected
```

**Docker.** После согласованной остановки прежнего запуска:

```powershell
docker compose up -d --build bot
```

Контейнер получает настройки из корневого `.env`; адрес API внутри Docker
установлен в `http://api:8000` через Compose. `bot/.env` для этого способа не нужен.
Запуск без флагов тоже выбирает подключённый режим.
Демо включается только явно: `python -m bot.main --demo` или `start-demo.cmd`.

## 4. Привязка аккаунта

1. Войдите на сайт привычным email и паролем, откройте «Словарь».
2. Нажмите «Подключить Telegram».
3. Откройте полученную ссылку, нажмите «Запустить» в Telegram.
4. Бот подтвердит имя подключённого аккаунта.
5. На сайте нажмите «Обновить статус Telegram»: появится подтверждение.

Ссылка одноразовая, действует 10 минут. Новая ссылка отменяет предыдущую.
Не передавайте её другим. При истечении срока получите новую на сайте.
Существующая чужая связь не заменяется; автоматического переподключения нет.
Пароль от сайта в боте не запрашивается.

## 5. Проверка общего словаря вручную

1. На сайте добавьте `bridge — мост`.
2. В Telegram откройте «📖 Мой словарь» или `/dictionary`: слово появится.
3. В боте выберите `/addword`, введите английское слово, перевод и подтвердите пару.
4. На сайте нажмите «Обновить список слов»: появится добавленная пара.
5. В боте откройте карточки, покажите перевод и поставьте оценку.
   Дату следующего повторения вернёт серверный SM-2, источник результата — `bot`.
6. На сайте обновите список и проверьте ту же дату.
7. Оценка «Не помню» добавляет слово в сложные: `/difficult`.
8. В словаре бота нажмите удаление нужного номера и подтвердите.
   На сайте обновите список: личная запись исчезнет.
   Общий справочник и словари других пользователей сохраняются.
9. Если слов больше восьми, проверьте кнопки «Назад» и «Вперёд».
10. `/cancel`, `/stop` и главное меню отменяют незавершённое добавление.
    До подтверждения сохранения нет. Старые кнопки не повторяют операции.

При недоступном сервере бот показывает ошибку, учебные слова не подставляет.
После обрыва при сохранении сначала обновите словарь: запрос мог успеть выполниться.
Автоматическое обновление страниц, LLM и генерация упражнений в этот этап не входят.

## Мини-тест, практика дня, прогресс и уровень

В подключённом меню /quiz («Мини-тест») открывает темы существующего курса сайта
и «Смешанный тест». Темы и задания загружаются через общий API; в тесте до пяти
различных упражнений. Если их меньше, бот показывает фактическое количество.
В текущем курсе пять тем и 30 упражнений. Повторный тест старается включить новые
задания, но банк конечен. LLM и демонстрационные слова не используются.

Выбор ответа — кнопкой; пропуск, перевод и сборка предложения — одним текстовым
сообщением. Для сборки бот показывает слова. После ответа появляются результат,
правильный вариант при ошибке, объяснение курса и кнопка «Следующий вопрос».
После последнего ответа нажмите «Показать результат»: бот покажет балл, темы ошибок,
«Пройти ещё раз» и «Главное меню».

/stop, /cancel и главное меню отменяют тест без новой попытки. Старые кнопки не
меняют результат. При обрыве связи повторите тот же ответ: сервер вернёт сохранённый
результат без второй записи. Без подтверждения API бот не сообщает об успехе.
Принятые ответы сохраняются в общих attempts/mistakes с источником bot и учитываются
существующей статистикой сайта после обновления страницы. Незаконченный грамматический
тест после перезапуска бота не возобновляется; принятые ответы остаются. Тест действует
четыре часа, затем нужно начать новый.

Тест по личным словам сохранён в подменю «Тест по моим словам» и команде /wordquiz.
Он использует до пяти различных личных слов и до четырёх вариантов перевода.
Когда вариантов недостаточно, слово нужно написать по переводу.
/daily остаётся отдельной практикой: до трёх карточек и до двух заданий на ввод.
При наличии примера показывается пропуск; иначе — перевод. Если слов мало, занятие короче.
Тест по словам и практика дня возобновляются после /stop и перезапуска.
После полного завершения практика дня открывается в новый день UTC (03:00 по Москве).
Повторная доставка ответа не применяет SM-2 дважды.
/progress показывает результаты словарных занятий и общий счётчик грамматических попыток.
/level сохраняет уровень в общем профиле; сайт покажет его после перезагрузки страницы.

Проверка грамматики вручную после включения обновления:

1. В связанном боте отправьте /start и нажмите «Мини-тест».
2. Выберите тему или смешанный тест, прочитайте правила.
3. Ответьте кнопкой либо текстом. Для проверки ошибки один раз ответьте неверно.
4. Проверьте объяснение и правильный ответ при ошибке; нажмите «Следующий вопрос».
5. Завершите тест и откройте результат, затем «Пройти ещё раз».
6. Проверьте /stop и старую кнопку: новой попытки быть не должно.
7. Обновите страницу курса сайта: решённые упражнения и ошибки используют общий аккаунт.
8. Откройте /wordquiz, /daily и словарь: прежние режимы должны оставаться доступны.

## Автоматические проверки

Бот: из папки `bot`, без сети, токена и чтения `.env`:

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

Backend использует отдельную тестовую БД с суффиксом `_test`. Изолированный вариант,
не читающий основной `.env` и не подключающийся к основной БД, из корня проекта:

```powershell
docker compose --env-file .env.example -f compose.test.yml up --build --abort-on-container-exit --exit-code-from test-api
```

Тестовая БД живёт в tmpfs, без пользовательских томов. Тестовые ключи предназначены
только для этой среды. Тесты проверяют конкурентную привязку, защиту чужих данных,
обмен словарём через настоящий API-клиент бота и общие результаты SM-2.

Тесты сайта `frontend/e2e/telegram.spec.ts` подменяют API; они не заменяют проверку
работающего сервера. Настоящий Telegram проверяется отдельным ручным сценарием выше.
