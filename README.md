# English Coach

Курсовой проект: сайт и Telegram-бот для изучения английского языка.
React + TypeScript, FastAPI, PostgreSQL и aiogram 3. Прогресс и личный словарь
общие для сайта и подключённого бота.

## Что работает

- **Курс A1–B1:** 15 тем, 90 упражнений; теория, выбор ответа, пропуски, перевод, сборка предложения.
- **Тематический словарь:** 6 разделов, 36 карточек с локальными иллюстрациями; добавление набора в словарь, SM-2.
- **Диагностический тест:** 24 вопроса, серверная проверка, разбор и история; отдельное подтверждение уровня.
- **Личный кабинет:** общая статистика сайта/Telegram, прогресс, результаты тестов, настройки напоминаний.
- **Telegram:** общий словарь, карточки, грамматические мини-тесты, практика дня и напоминания.

## Что остаётся отдельным этапом

**Настоящая LLM сейчас не подключена.** Интерфейсы собеседника и наставника сохранены,
но LLM_PROVIDER=stub не генерирует диалоги/планы. Это ещё не выполняет требование
курсовой об использовании LLM. [Бесплатные варианты](docs/llm-options.md) требуют
отдельного адаптера; в этом обновлении они не подключаются.

## Запуск на Windows через Docker

Откройте папку с docker-compose.yml в VS Code. В корневом .env укажите настройки БД,
свои JWT_SECRET и BOT_SERVICE_TOKEN, токен Telegram-бота и его имя без @.
Для запуска без модели явно установите LLM_PROVIDER=stub.

```powershell
docker compose up -d db
docker compose stop api web bot
docker compose build api bot
docker compose run --rm api alembic upgrade head
docker compose run --rm api python -m app.seed
docker compose up -d db api web bot
```

Сайт: **http://localhost:5173**. Зарегистрируйтесь, затем откройте
**«Словарь» → «Подключить Telegram» → «Открыть бота в Telegram» → «Запустить»**.
После подтверждения обновите страницу. Ссылка привязки действует 10 минут.

Стандартный API: http://localhost:8000/docs. При конфликте порта замените только
публикацию на `ports: ["8001:8000"]`; внутренние адреса http://api:8000 сохраняются.
Подробнее: [подключение сайта и бота](bot/CONNECTED-WINDOWS.md).

Остановка и следующий запуск:

```powershell
docker compose stop
docker compose up -d db api web bot
```

Повторный seed обновляет материалы без удаления аккаунтов и прогресса.
База сохраняется в Docker-томе; для обычного обновления этот том не удаляется.

## Где открыть новые функции

| Раздел | Возможность |
|---|---|
| «Словарь» | Тематические карточки, личные слова, привязка Telegram |
| «Личный кабинет» | Статистика, история тестирования, напоминания |
| «Личный кабинет» → «Пройти тест» | Диагностика A1–B1 |
| Telegram /reminders | Включение, время и часовой пояс напоминаний |
| Telegram /quiz, /wordquiz, /daily | Грамматика, слова, практика дня |

Диагностика — авторский ориентир, не сертифицированный экзамен; говорение и
аудирование не проверяются. Напоминания изначально выключены. При локальном
размещении нужны включённые компьютер, Docker и интернет; окно отправки после
пропуска — один час.

## Проверки

```powershell
docker compose --env-file .env.example -f compose.test.yml up --build --abort-on-container-exit --exit-code-from test-api
```

Бот: `docker compose run --rm bot python -m pytest -q`.
Frontend из frontend/: npm ci, npm run lint, npm run build.
E2E: npm run test:e2e против отдельной тестовой системы с загруженным курсом.
Секреты и дампы БД не включаются в Git.
