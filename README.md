# Курсовая работа "Создание веб-сайта и Telegram-бота для обучения английскому языку с помощью LLM"
Краткое описание:

Cистема не только дает темы и задания по выбору пользователя, но и адаптирует обучение на основе его результатов и ошибок.

## Сайт

изучение новых тем;

выполнение упражнений;

личный словарь;

просмотр прогресса и статистики;

рекомендации по дальнейшему обучению.

## Telegram-бот

повторение слов из словаря с сайта по принципу Quizlet;

короткие тесты и задания;

интервальное повторение проблемных слов;

быстрая ежедневная практика;

общение с виртуальным носителем языка.

## Роль LLM

Virtual Native Speaker - ведёт диалог на английском, подстраивается под уровень пользователя и выявляет ошибки;

адаптивный наставник - анализирует ответы, ошибки, прогресс и историю обучения;

предлагает, какие темы повторить или изучить дальше;

формирует персональный план занятия.

## База данных

хранит пользователей, темы, задания, ответы, ошибки, словарь, результаты диалогов и прогресс;

объединяет сайт и Telegram-бот в одну систему.
