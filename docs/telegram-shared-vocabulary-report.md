# Общий словарь сайта и Telegram: результат локальной работы

> Этот отчёт описывает предыдущий этап. Мини-тест, практика дня, прогресс и уровень впоследствии возвращены в подключённый бот: см. [обновление](connected-practice-update.md).

Работа начата от актуальной `origin/main` (`695264f`) в отдельной ветке
`feat/telegram-shared-vocabulary`. До начала рабочее дерево было чистым.
Новых коммитов, отправки на GitHub и Pull Request нет. Автор будущих коммитов — Ксения.

Основные файлы старой папки `F:\english-bot` отдельно сравнены с актуальной main:
более новых изменений исходников и скриптов не обнаружено. Папка не копировалась
поверх проекта, не изменялась и не удалялась. Секретные файлы не перезаписывались.

## Что реализовано

- На сайте в словаре есть подключение Telegram по одноразовой ссылке на 10 минут
  и явное обновление статуса связи. Прежние вход, регистрация и словарь сохранены.
- Сервер хранит SHA-256 кода в существующей таблице. Новая ссылка отменяет старую.
  Погашение кода и сохранение связи атомарны; конкурентный повторный запрос
  не использует код второй раз. Существующая чужая связь не заменяется.
- Сайт использует прежний JWT; бот — служебный ключ и Telegram ID отправителя.
  Пустые, стандартные и короткие служебные ключи не предоставляют доступ.
  Username и произвольный внутренний user_id не определяют владельца данных.
- Подключённый бот: «📖 Мой словарь», `/dictionary`, страницы по восемь слов,
  `/addword`, ввод слова и перевода, подтверждение добавления, подтверждение удаления,
  отмена и возврат в меню. До подтверждения данные не меняются.
- Карточки и сложные слова используют реальный личный словарь через API.
  Результаты сохраняются с источником `bot`, даты рассчитывает прежний серверный SM-2.
  Одновременные результаты сайта и бота не теряют обновления состояния.
- При ошибке API показывается сообщение без секретов и без подстановки демослов.
  Повторные и устаревшие кнопки не выполняют операцию второй раз.
- Демо сохранено отдельно через `--demo`. Обычный запуск и `--connected` используют
  подключённый режим. Схема БД и алгоритм SM-2 не менялись.

Стандартный Prettier без настройки окончания строк сообщал о CRLF в прежних файлах

Тесты PostgreSQL выполнялись только в отдельном Compose-проекте, без пользовательских
томов. Для повторения используйте явный `--env-file .env.example`, чтобы Compose
не загружал основной секретный `.env`. Миграции и учебный контент применялись
только к изолированной БД. Основной сайт, база и работающий бот не перезапускались.
Созданные тестовый API, Vite и тестовая PostgreSQL после проверок остановлены.

## Что не проверено и ограничения

- Настоящий Telegram-бот не запускался: нет проверки polling и доставки сообщений
  с реальным токеном. Имитация Telegram и служебный HTTP API обозначены отдельно.
- Рабочие секреты и настройки конкретного развёртывания не проверялись.
- LLM и автоматические напоминания не подключались.
- Мини-тест и практика дня в подключённом режиме явно недоступны; демо сохраняет их.
  Для следующего этапа предложены серверные учебные сессии и проверенные задания
  из курса вместо фиксированного словаря бота.
- Перепривязка и отключение существующей связи не добавлялись: чужая связь не заменяется.

## Как проверить самостоятельно

Подробная инструкция: [Windows и Docker](../bot/CONNECTED-WINDOWS.md).

1. Сохраните существующие настройки БД; задайте публичное имя бота и одинаковый
   случайный служебный секрет у backend и бота. Значения секретов не публикуйте.
2. Запустите базу, API и сайт. Если бот уже работает, отдельно согласуйте его
   остановку; после этого выберите один способ запуска подключённого режима.
3. На сайте войдите в аккаунт, откройте «Словарь» и подключите Telegram по ссылке.
4. Добавьте слово на сайте, запросите `/dictionary` в Telegram.
5. Добавьте другую пару через `/addword`, подтвердите, обновите список на сайте.
6. Повторите карточку в боте; проверьте общую дату на сайте после обновления.
7. Удалите слово через подтверждение в боте и обновите сайт. Проверьте навигацию
   при числе слов больше восьми, отмену и пустой словарь.

Не запускайте одновременно два процесса с одним Telegram-токеном.
