# Возврат учебных функций в подключённый бот

Статус: обновление включено 28 октября 2026 года в coursework-connected-local. Новые маршруты API и команды бота проверены.

Возвращаются «📝 Мини-тест», «☀️ Практика дня», «📊 Мой прогресс» и «🎚 Уровень».
Все данные берутся из общего аккаунта и личного словаря. Демо остаётся отдельно.

- Мини-тест: до пяти различных личных слов. До четырёх вариантов перевода из общего
  справочника; если нет второго варианта, используется ввод английского слова по переводу.
- Практика дня: до трёх карточек и до двух заданий на ввод. Для слова с подходящим
  сохранённым примером показывается пропуск; без примера — перевод. Короткий словарь
  означает короткое занятие, без искусственного повторения одного слова.
- Ответы и завершение дня сохраняются в PostgreSQL. Незавершённое занятие возобновляется.
  Повторный запрос возвращает сохранённый результат, не меняя SM-2 второй раз.
- Самооценки карточек не увеличивают число правильных ответов. Результаты используют
  прежний серверный SM-2 и источник bot; сайт видит те же следующие даты.
- Уровень A1–C2 сохраняется в существующем профиле пользователя и виден сайту после обновления.
- Помощь и прогресс не прерывают занятие; выход в меню прекращает локальный сценарий,
  а уже записанные ответы остаются. Практика дня доступна по дате UTC (03:00 по Москве).
- Разговор с LLM пока остаётся информационным разделом: генерация заданий не включалась.

Проверено: 109 тестов backend на отдельной PostgreSQL и 50 автономных тестов бота,
включая 30 прежних тестов демо. Ruff проходит. Проверены миграция, её откат и повторное
применение на временной БД; alembic check не находит расхождений.

Для сохранения сессий добавлены четыре новые таблицы: practice_sessions,
practice_questions, practice_choices и practice_answers. Существующие таблицы и данные
миграция не удаляет и не перестраивает. Статистика вычисляется из ответов; user_id хранится
только в сессии. next_review_at в ответе — историческая квитанция для безопасного повтора.

Список подготовленных файлов — bot/.ruff_cache/practice-next/manifest.json.
Код был проверен в отдельной временной копии и затем перенесён в основной проект. Секретные .env в копию не включались.

После согласования применена добавочная миграция feef7ec67795, перенесены проверенные исходники и пересоздан контейнер bot. Данные словаря, привязки и сохранённые результаты не удалялись.
Автоперезагрузка API не подхватила файлы в Docker. После отдельного согласования API однократно перезапущен. Новые маршруты проверены по HTTP; бот обращается к ним с действующим служебным ключом. База и сайт не останавливались.

Коммиты и отправка на GitHub не выполнялись.

## Проверка в Telegram

Отправьте /start, затем попробуйте /quiz, /daily, /progress и /level. Самостоятельно проверьте реальные ответы в Telegram; при технической проверке учебные записи в вашем аккаунте не создавались. Выбранный уровень на сайте виден после обновления страницы.
