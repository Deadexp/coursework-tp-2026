# Словарь и интервальное повторение — как пользоваться API

Памятка для сайта и Telegram-бота. Полное описание запросов и ответов — в Swagger: http://localhost:8000/docs (раздел **vocabulary**). Все запросы требуют заголовок `Authorization: Bearer <token>`.

## Сценарий «повторение слов» (Quizlet-режим)

1. `GET /vocabulary/review?limit=10` — карточки, которые пора повторить сегодня. Каждая карточка — слово и 4 варианта перевода (`choices`), один из них правильный (`word.translation`). Пустой список — на сегодня всё повторено.
2. Показываем слово, пользователь отвечает.
3. `POST /vocabulary/{word_id}/reviews` с оценкой `quality` и `source` (`"web"` или `"bot"`). Сервер пересчитывает, когда показать слово снова (алгоритм SM-2), и сохраняет историю.

### Какую оценку отправлять

| Что произошло | `quality` |
|---|---|
| Выбрал неправильный вариант / нажал «Не помню» | `1` |
| Ответил правильно, но долго думал / нажал «С трудом» | `3` |
| Ответил правильно | `4` |
| Нажал «Легко» | `5` |

Ответ сервера: `interval_days` — через сколько дней слово появится снова, `next_review_at` — точное время.

## Остальные запросы

| Запрос | Зачем |
|---|---|
| `GET /vocabulary` | Весь личный словарь с состоянием повторения |
| `GET /words?q=кош` | Поиск по общему словарю; `in_vocabulary` — уже добавлено или нет |
| `POST /vocabulary` `{"word_id": 5}` | Добавить слово из общего словаря |
| `POST /vocabulary` `{"text": "wolf", "translation": "волк"}` | Добавить своё слово |
| `POST /vocabulary/topics/{topic_id}` | Добавить все слова темы (ответ: сколько добавлено) |
| `DELETE /vocabulary/{word_id}` | Убрать слово из словаря |
| `GET /vocabulary/problem-words` | Слова, которые чаще всего не удавалось вспомнить за 30 дней — для «работы над ошибками» |

## Ошибки

`401` — нет или просрочен токен, `404` — слова нет (в словаре / в базе), `409` — слово уже в словаре, `422` — неверные данные (например, `quality` больше 5).
