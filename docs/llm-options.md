# Бесплатные варианты LLM — следующий этап

Проверено по документации поставщиков 12 ноября 2026 года. В этом обновлении
провайдеры не подключаются, ключи не запрашиваются, настоящие запросы не делаются.
Рабочий режим остаётся stub; прежний Anthropic-адаптер не включается.

| Вариант | Бюджет 0 | Ограничения |
|---|---|---|
| **Ollama + локальная модель** | Выполнение на своём компьютере, без оплаты запросов облачному API | Нужны память и место на диске; скорость зависит от компьютера. Размер модели выбирать после проверки RAM/GPU. Возможен режим без облачных функций |
| **Groq Free** | Бесплатный API с квотами; превышение даёт 429, а не платное продолжение | Нужны доступный аккаунт и интернет; проверить доступность и квоты в кабинете. Для бюджета 0 оставаться на Free, не переходить на Developer |
| **GigaChat Freemium** | Для физлиц предусмотрен бесплатный режим с лимитом токенов и сроком действия | Условия нового аккаунта проверить в кабинете; поставщик менял тарифы в 2026 году. Возможна дополнительная настройка сертификатов; бесплатность не считать бессрочной |

Для быстрой демонстрации на слабом ноутбуке сначала стоит проверить Groq Free.
Если желательно отказаться от облачного аккаунта — Ollama и небольшая локальная
модель после проверки характеристик компьютера. GigaChat — дополнительный вариант
при доступном Freemium; качество английского сравнить на одинаковых учебных примерах.

## При согласованном подключении

1. Добавить адаптер LLMClient с chat и parse.
2. Валидировать ответы Pydantic-схемами, проверять возвращаемые ID тем и рекомендации.
3. Проверить обе роли: собеседник на английском A1–B1 и наставник по реальной статистике.
4. Ограничить контекст/ответ, обработать timeout/429; не включать переход на платную модель.
5. Для Telegram отдельно завершить диалоговый UI и авторизацию общих маршрутов.

Один провайдер может выполнять обе роли с разными инструкциями. Голос — отдельная
функция. Одной замены LLM_PROVIDER недостаточно; stub не выполняет требование о LLM.
